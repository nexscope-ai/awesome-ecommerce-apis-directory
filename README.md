## Inclusion policy

An entry must meet all of the following requirements:

1. It has a publicly reachable official developer page or API reference.
2. Its documented use case directly supports an ecommerce marketplace, storefront, merchant, product, shopper, fulfillment, payment, commerce-data, or product-content workflow.
3. Its description is traceable to the linked official documentation.
4. An independent provider appears only once at its canonical documentation URL. The three disclosed Nexscope task pages are the intentional exception: each is also linked from its matching task category.

This directory does not rank providers, claim endorsements or partnerships, list prices, or guarantee coverage, uptime, eligibility, geographic availability, or data freshness. General-purpose infrastructure is included only when the linked documentation establishes a direct ecommerce use case.

## Contributing

Contributions are welcome. Please see [CONTRIBUTING.md](CONTRIBUTING.md) before opening an issue or pull request with:

1. The official developer-documentation URL — not a pricing page, reseller page, or affiliate link.
2. One concise, factual description supported by that documentation.
3. One of the five directory categories above.
4. The interface type when documented: `REST`, `GraphQL`, `MCP`, or `API` when a more precise public classification is unavailable.

For an update or removal, include the current documentation URL and a short explanation. Do not submit credentials, private endpoints, screenshots containing account data, or unverified claims.

## Maintenance and limitations

The list is maintained from public provider documentation. Links and descriptions should be rechecked before each merge and periodically after publication. A working documentation URL does not prove an API account is available to every user or that a particular endpoint is enabled.

Nexscope links in this repository use `co-from=github`. This attribution does not affect the inclusion or ordering of independent providers.
